All ten failing metrics were investigated and **every criterion was left exactly as it is**.
Thresholds in this suite are not widened to make a run green. The diagnoses below explain what
each failure means; acting on any of them is a decision for the method owners.

| Metric here                                            | Verdict here                 | What the diagnosis found                                                                  |
| ------------------------------------------------------ | ---------------------------- | ----------------------------------------------------------------------------------------- |
| `normalize_total.max_abs_error` = 1.220703125e-4       | FAIL vs `<= 1e-5`            | Exactly one float32 ULP at the largest normalized value (1751.05); unreachable in float32 |

| `umap.gpu.trustworthiness` = 0.86983                   | FAIL vs `>= 0.9`             | Same; the GPU value sits inside the CPU's own seed-to-seed range                          |
